# FoxFetch v1.0.0 Beta

## 简体中文

FoxFetch 将网页媒体发现、浮动播放控制和文件下载整合在一个 Chrome 扩展中。

- 资源中心：查看、搜索和筛选页面中的视频、音频和图片。
- 浮动控制器：播放、暂停、调速与静音控制。
- 专用站点适配：Bilibili 与 YouTube 媒体下载，实际可用性取决于来源与账号权限。
- 下载偏好：兼容、画质、体积；适用的失败场景会有限尝试其他格式组合。
- 中英文界面、浅色与深色主题、浮动设置及任务诊断。

这是 Beta 测试版，不是稳定版承诺。本次以已有 0.14.27 功能为基础统一版本标识与介绍，不改动下载流程。仅下载你拥有或获准下载的内容；不绕过 DRM、付费限制或服务端验证。

安装：下载 `FoxFetch-v1.0.0-Beta-chrome.zip`，解压后在 Chrome 扩展管理页开启开发者模式，选择“加载已解压的扩展程序”。请勿将 GitHub 自动生成的 Source code 包作为安装包。

## English

FoxFetch brings webpage media discovery, floating playback controls, and file downloads together in one Chrome extension.

- Resource center: browse, search, and filter videos, audio, and images found on a page.
- Floating controller: play, pause, adjust playback speed, and toggle mute.
- Dedicated Bilibili and YouTube download workflows, subject to source availability and account permissions.
- Download preferences: Compatibility, Quality, and Size, with bounded format fallback for eligible failures.
- Chinese and English interfaces, light and dark themes, floating settings, and task diagnostics.

This is a Beta release, not a guarantee of stable operation. This release updates version labels and documentation on the existing 0.14.27 feature baseline without changing the download pipeline. Only download content you own or have permission to download. FoxFetch does not bypass DRM, paywalls, or server verification.

Installation: download `FoxFetch-v1.0.0-Beta-chrome.zip`, extract it, enable Developer mode on Chrome's extensions page, and choose **Load unpacked**. GitHub's automatically generated Source code archives are not installation packages.
