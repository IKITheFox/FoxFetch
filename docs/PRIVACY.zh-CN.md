# 隐私与权限

[English](PRIVACY.md) | 简体中文

本文适用于 FoxFetch v1.0.0 Beta 的 GitHub 分发版本。

## 数据处理

FoxFetch 在浏览器本地处理识别到的媒体并合并受支持的媒体流。资源识别及下载会向原网站和媒体服务器发送请求，对应服务按自身政策处理请求；本地处理不代表离线运行。

媒体标题、URL、格式元数据及任务状态用于显示资源和管理下载。设置通过 Chrome 存储保存；浏览器同步可用时，受支持的设置使用同步存储。本地／会话存储和浏览器临时文件用于处理任务。已保存文件保留在你选择的目标位置。

特定站点的下载可能使用网站已有的浏览器会话。FoxFetch 不要求你向扩展粘贴账号密码或 Cookie。

## 权限

| 权限                                | 用途                                                     |
| ----------------------------------- | -------------------------------------------------------- |
| activeTab、tabs、scripting          | 识别当前页面、发现受支持的媒体并添加播放控制。           |
| storage                             | 保存设置及任务相关状态。                                 |
| downloads                           | 保存文件并跟踪浏览器下载结果。                           |
| offscreen                           | 在可见界面之外运行媒体处理。                             |
| unlimitedStorage                    | 支持媒体临时存储，但仍受设备剩余空间限制。               |
| sidePanel                           | 在 Chrome 侧边栏显示资源中心。                           |
| declarativeNetRequestWithHostAccess | 为受支持的媒体流程应用限定范围的请求规则。               |
| Bilibili／YouTube 网站访问          | 启用扩展清单中声明的专用站点适配。                       |
| 可选 webRequest 与 HTTP(S) 网站访问 | 获得授权后观察允许的媒体请求，并支持其他网站的资源识别。 |

可在 Chrome 扩展设置中查看或撤销网站访问权限。撤销后，对应识别或下载功能可能不可用。

## 数据控制与反馈

通过 Chrome 扩展管理功能停用或移除 FoxFetch，并管理其存储。移除扩展不会删除已经保存到下载目录或其他位置的文件。浏览器同步设置由 Chrome 管理。

主动复制的诊断信息可能包含标题、来源信息、任务编号及错误。公开前请检查，不要分享认证数据或带签名的下载链接。GitHub Issue 对公众可见；安全漏洞应使用[私密报告](../SECURITY.zh-CN.md)。

如对本文有疑问，可提交 Issue，但不要附带私人账号或浏览信息。
